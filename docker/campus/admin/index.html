在网关里做什么

  • 换上游或改密钥：渠道 → 选择上游渠道 → 改「代理地址」和「密钥」。密钥只填进这里，不要写进聊天、脚本或日志。
  • 开放新模型：先在「运营设置 → 模型倍率」为它配好 ModelRatio／CompletionRatio，再把模型名加进渠道的模型列表。
  • 模型改名：渠道的「模型重定向」把用户看到的名字翻译成上游的真名，用户侧和倍率表都不用动。

未定价的模型一律不要加进渠道 —— 网关对没有倍率的模型会按兜底价计费，比真实价高约五百倍。manage.sh verify 会因此失败，这是刻意设计的护栏。
